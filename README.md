# Registro Inmobiliario - Descargas

Repositorio público destinado **únicamente a distribuir versiones compiladas** de `DescargaCertificadosYPlanos`.


## Descargar

Ve a [Releases](../../releases) y descarga el `.exe` de la versión que corresponda.

## Requisitos

- Windows 10 o posterior.
- Conexión a internet para la activación inicial y verificaciones periódicas.
- Microsoft Word o LibreOffice si se importan documentos `.doc`/`.docx`.

## Licencia

El software es propietario. La descarga del ejecutable no concede propiedad sobre el software. Cada cliente necesita una licencia de uso válida y una clave de activación emitida por el proveedor.
